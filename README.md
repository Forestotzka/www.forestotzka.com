# えありぷの森

Astroで作った、Markdownベースの個人ブログです。AtCoderの参加記録や日記を、記事とタグで管理します。

## ローカルで動かす

```bash
npm install
npm run dev
```

ブラウザで http://localhost:4321/ を開いてください。

## 記事を追加する

リポジトリ直下の `posts/` に、記事ごとのディレクトリを作成します。ディレクトリ名がURLのスラッグになります。

```md
posts/hello/index.md
```

```yaml
---
title: 記事のタイトル
description: 記事の概要
date: 2026-10-22
tags:
  - 日記
authors:
  - rarula
thumbnail: ./thumbnail.png
---
```

本文はFrontmatterの後に続けて書きます。記事内の画像やサムネイルは、同じ記事ディレクトリに配置して相対パスで参照できます。

たとえば `posts/hello/index.md` は `/posts/hello/` で表示されます。

`thumbnail` は任意項目です。指定した画像は記事詳細の最上部と記事カードに表示され、クリックすると拡大できます。未指定の場合もカード内のサムネイル領域は残り、サイトの淡い緑色のフォールバックが表示されます。

`authors` には登録済みメンバーのIDを指定します。未登録のIDも指定でき、その場合は名前だけが表示されます。メンバーの追加・変更は `data/members.json` で行います。

メンバーJSONでは、`skills` にスキル名の配列を、`portfolios` にポートフォリオの配列を設定できます。ポートフォリオには `title`、任意の `url`、`description`、`tags` を指定できます。スキルとポートフォリオのタグは、対応する記事タグページへのリンクとして表示されます。

登録済みメンバーの執筆者名やアイコンからは、そのメンバーの記事一覧（`/members/[id]/`）へ移動できます。未登録の執筆者にはフォールバックアイコンが表示されますが、メンバー記事一覧へのリンクはありません。

本文では `$...$` のインライン数式と `$$...$$` のブロック数式を利用できます。ビルド時にKaTeXへ変換されます。

コードブロックはマウスホバーまたはフォーカスでコピー用ボタンが表示されます。横長のコードをスクロールしても、コピー用ボタンは表示領域の右上に固定されます。`mcfunction` のシンタックスハイライトにも対応しています。

記事本文内の画像はクリックすると拡大表示できます。画面内のどこかをクリックするか、Escapeキーで閉じられます。

存在しないURLには404ページを表示し、トップページと記事一覧へのリンクを案内します。サムネイル未指定の記事カードでは、`public/images/post-thumbnail-fallback.svg` をフォールバック画像として表示します。未知の執筆者には `public/images/members/fallback.svg` を表示します。

サイト共通のcanonical URL、Open Graph、Twitterカードを出力します。記事では設定したサムネイル、それ以外のページでは `public/images/site-eye-catching.png` を `summary_large_image` の画像として使用します。絶対URLの基準は `PUBLIC_SITE_URL` 環境変数で変更でき、未設定時はAstroのサイト設定またはローカルURLを使用します。

サイト内の静的画像、メンバーアイコン、記事カード・記事詳細のサムネイル、ライトボックスの初期画像はAstroの `Image` コンポーネントで扱います。Markdown本文の相対画像は記事ディレクトリ内に配置して従来どおり記述できます。

本文・見出し・UIには `@fontsource/noto-sans-jp` で同梱したNoto Sans JPを使用しています。端末にインストールされたフォントへ依存しないため、PCとスマートフォンで同じフォントを表示できます。コードブロックは等幅フォント、数式はKaTeXのフォントを使用します。

ページ初期表示時のちらつきを避けるため、ヘッダーや初期表示範囲の記事・メンバー画像は先読みし、記事本文や画面下方の画像は遅延読み込みにしています。

ヘッダーのサイトアイコンは `src/assets/site-icon.png` で管理し、Astroで最適化した画像をpreloadします。ブラウザのfaviconには `public/images/favicon.ico` を使用します。元画像が大きい場合でも、表示サイズに近い軽量な画像を先に読み込むことで、ページ遷移時のヘッダー画像のちらつきを抑えます。

ヘッダーは下向きスクロール時に隠れ、上向きにスクロールすると再表示されます。

サイト内のページ遷移にはAstroのView Transitionsを使用し、共通ヘッダーをページ間で保持します。読み込み済みのフォントCSSとサイトアイコンを再利用することで、遷移直後に端末標準フォントが一瞬表示される現象を抑えます。

記事一覧では開始日・終了日を指定して記事を絞り込めます。メンバーのSNS URLは `data/members.json` の `socials` に設定します。`twitter`、`youtube`、`discord` はアイコン、それ以外はURL文字列として表示されます。

記事一覧の「フィルタ・並べ替え」から、日付の範囲と新しい順・古い順を指定できます。SNSのその他URLはドメイン名のボタンとして表示されます。

記事一覧、タグ検索結果、メンバー個別ページの執筆記事一覧では、表示形式を1列・3列から選択できます。選択状態はブラウザの `localStorage` に保存され、対象ページで共有されます。小さい画面では常に1列で表示し、トップページの「最近の記事」は固定の3列表示です。

タグ一覧は `/tags/` で表示し、URLに `/`、`?`、`#` を含まないタグを選択すると `/tags/タグ名/` の静的な記事一覧へ移動します。これらの文字を含むタグは、URLのパスとして安全に扱えないためリンクなしで表示されます。タグページはビルド時に対象記事だけを生成するため、クライアント側のフィルタ処理に依存しません。

メンバー一覧ではアイコン付きSNSだけを表示し、メンバー個別ページではその他URLもドメイン名のボタンとして表示します。記事一覧のURLにフィルターや並べ替えのパラメータがある場合は、設定パネルが自動的に開きます。
